# 🛒 E-Commerce App (MERN Stack)

An E-Commerce web application built with the MERN (MongoDB, Express.js, React.js, Node.js) stack. It supports product browsing, cart functionality, user authentication, and admin dashboard for product and order management.


## 🚀 Features

- 🛍️ User-friendly product browsing
- 🔍 Product search and filtering
- 🛒 Add to cart & checkout functionality
- 🔐 User authentication (JWT)
- 👨‍💻 Admin panel for product & order management
- 📦 Order tracking
- 🖼️ Product images and descriptions
- 💳 Stripe payment integration
- 🌐 Fully responsive frontend

## 🧑‍💻 Technologies Used
- Frontend : React.js,
             React Router,
             Redux / Context
- Backend :  Node.js,
             Express.js
- Database : MongoDB,
             Mongoose
- Others :   JWT Authentication,
             Stripe API,
             dotenv, multer
